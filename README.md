# 🛒 E-Commerce Sales Dashboard

##  Project Overview

The **E-Commerce Sales Dashboard** is a data analytics and visualization project designed to analyze e-commerce sales data and transform raw transactional data into meaningful business insights.

The project involves **data cleaning, exploratory data analysis, and interactive dashboard visualization** to understand sales performance, customer behavior, product performance, and overall business trends.

The analysis is performed using **Python and Jupyter Notebook**, while **Tableau** is used to create the interactive sales dashboard.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze e-commerce sales data.
* Clean and preprocess raw transactional data.
* Identify important sales trends and patterns.
* Analyze product and category performance.
* Understand customer purchasing behavior.
* Analyze sales across different regions.
* Identify high-performing and low-performing products.
* Create meaningful visualizations from the cleaned data.
* Develop an interactive dashboard using Tableau.
* Generate business insights that can support better decision-making.

* Identifying missing values.
* Checking duplicate records.
* Checking data types.
* Cleaning inconsistent data.
* Converting required columns into appropriate formats.

## ▶️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/deepasharma04332-sketch/E-commerce-Sales-Dashboard.git
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd E-commerce-Sales-Dashboard
```

Open the `DA PBL` folder.

### 3. Run the Jupyter Notebook

Make sure Python and Jupyter Notebook are installed.

Open:

```text
E-COMMERCE_SALES.ipynb
```

Run the notebook cells sequentially to reproduce the data analysis.

### 4. Open the Tableau Dashboard

Open the following Tableau workbook using Tableau Desktop:

```text
ecommerce_sales.twb
```

The dashboard can then be explored using Tableau's interactive features.
